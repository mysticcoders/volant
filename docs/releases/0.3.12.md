## New

- **Rex panes in the launcher.** Type `rex` to see the terminal panes of [Rex](https://www.superlogical.com/rex), with the ones waiting on you first, then failed, done, working and idle. Each row shows the project, session, program and what it last reported, such as a question from Claude Code. Add a word to filter (`rex deploy`). Press Return to switch Rex to that pane and bring it forward. (#276, #277)
- **Rex in the footer.** Turn on Rex pane activity in Settings → Status Bar to see "Rex: 2 waiting" in the launcher footer. Click it to open the list. (#276)

Switching Rex to a pane in another session needs Remote Control turned on in Rex Settings → Rex Server; Volant tells you when it's off. Volant reads only the status programs report to Rex on this Mac, never a pane's contents, never types into a pane and never starts Rex.

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
