## New

- **A blended launcher.** The lines under the search field and above the footer are gone, so the window reads as one surface. Results fade into the footer's translucent top edge, and the footer is solid beneath its labels so they stay easy to read. With Reduce Transparency on, the footer stays solid and keeps its lines. (#317)
- **Extensions can read your clipboard, when you allow it.** An extension that declares the new clipboard permission says so when you enable it: "Read your clipboard's text when you run it." Volant reads the clipboard once when you run the extension, never while you search. It sends plain text only, up to 64 KB, and nothing from a password manager or any item marked concealed. Volant doesn't store or log it. (#308)
- **Text commands can use preferences and saved data.** A text command can now take the same kind of request a list extension gets, with its preferences, its saved data and, if allowed, the clipboard. (#308)

## Changed

- **Typing in an extension stops the search it replaces.** In a list extension such as Hacker News, a new query no longer waits for a slow earlier one to finish loading; the earlier one stops and its results are dropped. Leaving the extension or closing the launcher stops it too. Row actions are never interrupted. (#307)

## Security

- **Exchange-rate downloads stop at their size limit as the data arrives**, instead of after it is received. (#312)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
