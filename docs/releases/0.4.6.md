## New

- **Find git worktrees, and get the space back.** Type `worktrees` (or `wt`) to see the git worktrees on your Mac, largest first, with their size, uncommitted changes and the age of the last commit. Worktrees a dev server or agent is working in are listed first under In Use, and ones whose folder is gone are listed under Stale. Type `worktrees stale` or other text to filter. Return reveals one in Finder and Command-Return copies its path; Actions open it in Terminal or copy its branch name. (#437)
- **Remove a worktree safely.** Remove Worktree… in Actions asks first, and nothing is removed by pressing Return. Right before removing, Volant checks again that the worktree is unchanged, not locked, has no program working inside it, and has no commits that only it holds. Uncommitted changes and new files are saved to Application Support › Volant › Worktree Backups first, and the branch is kept. Files git ignores, such as build output or a .env file, are deleted with the folder. Prune Stale Worktrees clears git's records of worktrees whose folders are already gone. (#438)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
