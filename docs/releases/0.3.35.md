## New

- **Pick a color from anywhere on screen.** Type `color picker` (or `pick color`, `eyedropper`) and press Return: macOS's loupe appears, and after you click, Volant shows the color as HEX, RGB, HSL and OKLCH with a swatch. Return copies the format you choose. No permission is needed, and the color is kept only until Volant quits. (#367)
- **Open Camera.** Type `camera` for a small, mirrored preview from your Mac's camera, for a quick check before a call. Escape or closing the window stops the camera; nothing is recorded or saved. Volant asks for Camera access the first time you use it, never at launch. (#367)
- **Toggle Dark Mode and menu bar hiding.** Type `dark mode`, `light mode` or `menu bar` to switch your Mac's appearance or whether the menu bar hides automatically. The row shows the current setting. The first time, macOS asks to let Volant control System Events; Volant controls nothing else. The menu bar toggle switches between always hiding and never hiding; System Settings keeps the other choices. (#367)
- **Extensions can copy logos, images and long text.** An extension you allow can offer rows that copy more than a line, such as a company's SVG logo or a site's icon. Volant asks first ("Copy text and images to your clipboard when you choose them"), fetches the file only when you choose Copy, from a site you have already approved, and checks it is the kind of file the extension says before copying. Extensions never write to your clipboard on their own. (#366)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
