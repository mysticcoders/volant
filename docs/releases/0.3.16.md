## New

- **See the servers you're running.** Type `servers` or `ports` to list the local servers listening on this Mac: one row per port, with the runtime's logo (Node.js, Python, Ruby, PostgreSQL, Redis and more), the folder it was started in, its process ID and how long it has been running. Each row says Local, or Network when other machines can reach it. Return opens `http://localhost:<port>`, ⌘↩ copies the URL, and Actions copy the port or process ID or show the program in Finder. Type more to filter, such as `servers 3000`; `servers all` adds macOS's own services. Volant reads only your own processes, never their arguments, and doesn't stop anything. (#292)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
