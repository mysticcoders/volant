## New

- **Extension preferences.** List extensions can now offer settings, such as how many stories to show or a minimum score. Open them from an extension's **Preferences…** button in Settings › Extensions. A preference only changes what the extension shows: it can't reach a new site or hold a password. Preferences are kept in Volant's config file on this Mac and included in backups, but never synced through iCloud. Hacker News is the first to use them, with stories to show, minimum points, and whether rows show points and comments; its update arrives from the extension catalog alongside this release. (#303)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
