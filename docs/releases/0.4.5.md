## New

- **AI apps can ask for more, and Volant asks you first.** Connected Apps in Settings › AI has four new switches, each off by default: search clipboard history, search file names, convert currency and check the weather. Every such request shows a prompt in Volant that names the app and exactly what it wants, for example "Claude Code wants to: Search your clipboard history for “invoice”". Choose Deny, Allow Once or Always Allow. Nothing is chosen for you, and a prompt you leave alone is denied after a minute. Clipboard results are text only, file search returns names and paths but never contents, and weather is for a place you name, never your location. Ask Again forgets an app's Always Allow choices. (#428)
- **Let AI apps run Focus and Breaks.** With their own switches, an AI app can start, pause, resume and end a Focus session, and take, end, skip or pause breaks. Starting Focus from an AI app uses your remembered block list and never changes it. (#427)
- **Notes, snippets and quicklinks as resources.** AI apps that support MCP resources can browse your snippets, quicklinks and notes directly, as well as through tools. (#427)

## Also

- Connected Apps shows Claude Code, Codex, Cursor and Claude Desktop by name.
- Volant tells AI apps its name and asks them to use its tools rather than look for Volant's files, which macOS keeps private.

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
