## New

- **Search the menus of the app you were using.** Turn on **Search Menu Items** in Settings › General, then type `menus` (or `menu items`) and a few letters to search the menu bar of the app that was in front when you opened Volant. Each row shows the item's menu path and shortcut, and Return chooses it. Volant's input helper reads only menu titles, shortcuts and whether an item is enabled; it never reads text from windows or fields, never touches the Apple menu, and keeps the titles only while the launcher is open. It uses the same single Volant entry in Privacy & Security › Accessibility as Type at the cursor, and is off until you turn it on. (#373)
- **SVG logos show in extension rows.** An extension you allow to show images in its rows can now show SVG logos too. Volant checks each file first and refuses anything that could reach another file or the network, run a script, embed a page or another image, or grow too large; Volant's extension helper, which has no network access, then draws it into a small picture within a one-second limit. (#375)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
