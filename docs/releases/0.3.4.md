## New

- **Extensions can use your account.** An extension that needs a personal API token asks for it once. Volant keeps it in your Keychain and adds it only to requests to that extension's own host; the extension never sees it. Remove it any time in Settings → Extensions. (#245)
- **Extensions can act, not just list.** Rows can offer actions that change something on the site, such as completing a task, after asking you to confirm. Return runs a row's main action. (#245)
- **Extensions can open their own app.** A row can open the matching app, such as a task in Todoist, and falls back to the web link when the app isn't installed. (#246)
- **Location for extensions you allow.** An extension can ask for your approximate location (about 11 km), for example to show local weather. You allow it per extension, and it's shared with that extension and the sites it reads. Volant asks macOS for it only when the extension runs and never saves it. Settings → Extensions → Location lists every extension you've allowed. (#247)

## Changed

- Extensions can fetch in up to three rounds, know whether you use US or metric units, read pages up to 512 KB, and keep up to 256 KB of their own data. (#242)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
