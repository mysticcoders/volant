## New

- **Extension catalog.** Settings → Extensions → Catalog lists extensions reviewed for Volant, starting with the Hacker News and Lobsters readers. Choose **Check Catalog**, then **Install**. Each listing shows its publisher, license, the hosts it reads and a link to the exact source it was built from. (#218)
- **Signed installs and safe updates.** The catalog is signed, and every download is checked against it before anything is installed. Installing never turns an extension on or runs it, and an update with changed code, permissions or hosts stays off until you enable it again. A failed update puts the previous version back. (#218)

## Privacy

- Volant contacts the catalog only when you choose Check Catalog. The download goes through the same sandboxed helper that network extensions use, and only to the catalog's one fixed address. The Volant app itself still has no network access. (#218)

Requires macOS 15 or later. Apple silicon and Intel.
