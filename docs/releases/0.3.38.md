## New

- **Pick Another Color.** After you pick a color, the HEX, RGB, HSL and OKLCH rows are followed by **Pick Another Color**, which opens macOS's loupe again. HEX is still selected, so one Return copies it. (#378)
- **Try Volant in your browser.** The website's new homepage and [usevolant.com/try](https://usevolant.com/try) let you type into Volant before installing it: real Volant extensions and Volant's own calculator, running in your browser. (#374, #377)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
