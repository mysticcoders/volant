## New

- **Redesigned Settings.** A searchable sidebar with colored icons, rounded cards without separator lines, and more room throughout. Settings takes your color theme's colors, so Catppuccin, Nord, Rosé Pine and the others now restyle it too. General is split into focused sections: Keyboard Shortcuts, Dictation and File Search have their own, and a new About section shows the version and acknowledgements. (#236)
- **What's New, in the app.** Settings → What's New shows the notes for every release, and the launcher menu's What's New item opens it. (#240)
- **File search through fsearch, if you run it.** If the [fsearch](https://github.com/noahdunnagan/fsearch) daemon is running on your Mac, turn on Settings → File Search → Use fsearch for file search to get whole-disk file results that tolerate typos, plus fsearch's filters after `/`, such as `/ext:swift launcher`. Volant does not include, install or start fsearch, and it uses Spotlight whenever fsearch isn't running. Off by default. (#234)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
