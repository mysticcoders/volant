## New

- **Extensions can show pictures in their rows.** An extension you allow can show each row's own image in place of its icon, such as a site's favicon. Volant asks first ("Show images from its sites in its rows"), loads images only for rows on screen and only from sites you have already approved, and keeps them in memory until Volant quits. Images are downloaded and shrunk by Volant's sandboxed network helper, which hands the app only a small, freshly drawn PNG; SVG images are never drawn. (#370)
- **Extensions can copy any kind of image.** Copying an icon or logo now works whatever format the site sends: PNG, JPEG, GIF, WebP, ICO, BMP, TIFF, AVIF or HEIC. When an ICO holds several sizes, Volant copies the largest. (#370)

## Fixed

- **More SVG logos copy.** SVG files that begin with a comment or a `<!DOCTYPE svg>` line, such as some logos on svgl, now copy instead of being refused. (#370)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
