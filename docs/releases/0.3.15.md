## Changes

- **Volant's data now uses its own name.** Up to 0.3.14, settings, notes, clipboard history and extensions were kept in a folder and Keychain item still named Vey, the app's name before Volant. The first time 0.3.15 opens, it moves them to Volant. Your notes, pins, clipboard history, extensions and approvals come with them; there's nothing to do. After that, going back to 0.3.14 would start without them. (#288)
- **Extension errors show in the launcher.** When a command extension failed, the launcher kept showing the row you chose and hid the reason. It now shows the error. (#289)

## For extension developers

- **ABI 1 imports are now in the `volant` namespace.** Modules that still import from `vey` are refused and need rebuilding. No catalog extension imports either, so none are affected. (#288)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
