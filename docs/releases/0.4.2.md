## New

- **A Welcome window for new installs.** The first time Volant opens on a Mac, it walks you through your shortcut, what you can type (with Try It for each, now including `weather`, `focus` and `breaks`), the access Volant can use, the agents it found and its extensions. Try It and Chat open the launcher on top, so you can keep going afterward. If you already use Volant, it won't appear on its own; type `welcome` or open it from Settings › About. (#365)
- **Updates show up in the launcher.** When Volant finds an update while you're working in another app, the first row in the launcher becomes Update Volant to the new version, and Return installs it. You no longer have to catch the update window or remember Check for Updates. (#410)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
