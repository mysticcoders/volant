## New

- **Extensions that read the web.** Community extensions can now show live lists, starting with the [Hacker News and Lobsters readers](https://github.com/mysticcoders/volant-extensions): type `hn` or `lobsters` to see the front page, Return to open a story, Command-Return for its discussion. The extension itself still has no network access. It asks for the exact hosts it needs, Volant shows them to you first ("To use this extension, Volant needs to allow access to the following hosts"), and a separate sandboxed helper fetches only from hosts you allowed. (#214)
- **Network Access in Settings.** Settings → Extensions lists every host you allowed and which extensions use it. Remove takes a host away from all of them at once; they ask again next time. (#214)
- **Uninstall extensions.** Community extensions now have **Uninstall…**, which moves them to the Trash and removes host access no other extension needs. (#214)

## Fixed

- Settings → Extensions now shows changes made from the launcher, such as enabling an extension, without switching panes. (#214)

Requires macOS 15 or later. Apple silicon and Intel.
