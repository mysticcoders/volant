## New

- **European Portuguese (beta).** Volant now has European Portuguese alongside Brazilian Portuguese, written separately with Portugal's own terms (Definições, ficheiro, "A carregar…"). Settings › General › Language lists them as Português (Portugal) and Português (Brasil), and a Mac set to Portugal's Portuguese now gets it automatically. Like every translation, it's a beta drafted without review by native speakers; Settings › About links to report problems. (#301)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
