## New

- **File search through fsearch, if you run it.** If the [fsearch](https://github.com/noahdunnagan/fsearch) daemon is running on your Mac, turn on Settings → General → File Search → Use fsearch for file search to get whole-disk file results that tolerate typos, plus fsearch's filters after `/`, such as `/ext:swift launcher`. Volant does not include, install or start fsearch, and it uses Spotlight whenever fsearch isn't running. Off by default. (#234)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
