## New

- **Extension updates show up in the launcher.** When an installed extension has a newer version in the catalog Volant last checked, the launcher's suggestions start with **Extension Updates Available**, naming each one; Return opens Settings › Extensions to update. Showing it never contacts the catalog. (#324)
- **Check for updates daily.** A new switch in Settings › Extensions, off by default, lets Volant check the signed catalog once a day by itself, so updates and withdrawals reach you without opening Settings. It never installs or updates anything on its own. (#324)
- **Catalog icons before you install.** Extensions in the catalog now show their own icons in the launcher and in Browse Extensions, not only after installing. Each icon is checked against the signed catalog. (#322)

## Changed

- **Long AI Chat conversations stay light while a reply streams.** Volant now receives only the message that changed instead of the whole conversation a few times a second. In measurements of a 1 MB conversation, memory churn fell from about 27 MiB to under 1 MiB a second and CPU time from 20 ms to under 2 ms a second. (#321)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
