## New

- **Updates for every extension at once.** Settings → Extensions now lists only the extensions you have installed. Choose Check for Updates, then Update All, or update one extension at a time. An update keeps an extension turned on unless the new version asks for access the old one didn't have, such as a new site to read. (#270)
- **Browse Extensions.** Find and install new extensions from Browse Extensions in Settings, in a window of its own with search. (#270)
- **Withdrawn extensions are turned off.** If an extension is withdrawn from the signed catalog, Volant turns it off the next time you check for updates, shows why, and won't run or reinstall that version. (#270)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
