## New

- **Volant in 13 more languages (beta).** Volant now speaks Spanish, German, French, Italian, Japanese, Simplified Chinese, Brazilian Portuguese, Korean, Dutch, Polish, Russian, Ukrainian and Turkish, following your Mac's language. Every translation is a beta drafted without review by native speakers, so some wording may be off. Settings › About says so, with a link to report problems. Plurals follow each language's rules, and typed commands like `servers` stay the same in every language. (#296, #297, #298, #299)
- **Choose Volant's language.** Settings › General › Language picks System or any of the 14 languages by its own name, then relaunches Volant to apply it. It's the same per-app setting as System Settings › General › Language & Region › Applications. (#299)

Some messages still appear in English in other languages, such as some calculator, agent and extension details. Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
