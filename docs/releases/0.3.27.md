## Changed

- **Extensions run faster and lighter.** Volant now hands each extension's code to its sandbox in one copy instead of a slow conversion, so a run of a larger extension such as Base64 Encode takes about 6 ms instead of 43 ms, and the extension helper's peak memory is about 30 MB lower. (#330)
- **More of Volant appears in your language (beta).** Messages that include a number or name — status lines, extension errors, relative dates and more — and messages from Volant's helpers are now translated in every beta language, instead of appearing in English. Translations are unreviewed betas. (#331)

Requires macOS 15 or later. Apple silicon and Intel. Dictation requires macOS 26.
