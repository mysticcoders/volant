# ICU data items the /try calculator keeps (tools/try-wasm/icu-data.mjs trim). Globs over item names
# without the icudt76l/ prefix. Everything else in ICU's 34 MB common data is dropped: converters,
# collation, break iteration, transliteration, string prep, normalization, Unicode names, language
# and region names, and every non-English locale. The demo answers in English only.
#
# Verified with tools/try-wasm/parity.mjs (full vs trimmed module, 80 queries with fixed rates:
# identical) and the 26-query native comparison against the app (identical). keep-prune.sh tests
# dropping entries one by one; small locale-fallback tables stay for queries the parity set lacks.
# Result: 40 of 4855 items, 1.79 MB of 33.98 MB.
